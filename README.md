## 概要

合奏の長時間録音を、そのままアップロードして仲間と共有するための録音プレーヤー。身内向けのため非公開です（このページの起動ボタンは無効になっています）。

### しくみ
団体ごとにパスワードで入る共有スペースに、録音ファイルをアップロード。
管理者だけでなく閲覧者でも「区間（セクション）」を設定して整理でき、区間だけ再生したりダウンロードしたりできます。

基本用途は「録音担当による曲の切り分けの負荷を減らす」で、
応用としては閲覧者が自由に区間を作ってダウンロードすることで練習用の部分音源を簡単に作成できます。

### 機能
再生／編集／設定のモード切替、ファイルの名前変更・複製・削除、保存容量のゲージと保持期限の表示、管理者用の管理まわり。

### 画面説明（スクリーンショットの見方）
1) 入口: 団体のパスワードを入れて「入る」。
2) 管理者ログイン: 運営用の入口。本体はログイン後のため、ここでは入口のみ掲載しています。
