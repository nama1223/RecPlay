## Overview

A recording player for uploading and sharing long recordings of ensemble performances. It's private for internal use only (the launch button on this page is disabled).

### How it works
Upload recording files to a shared space accessible by password for each group.
Both administrators and viewers can organize recordings by setting "sections," allowing them to play or download only specific sections.
The primary purpose is to "reduce the burden on the person in charge of recording, who would otherwise have to split the tracks."
As a secondary use, viewers can freely create their own sections and download them as practice clips.

### Features
Mode switching for playback/editing/settings, file renaming, duplication, and deletion, storage capacity gauge and retention period display, and administrator management features.

### Screen Explanation (How to read screenshots)
1) Entrance: Enter the group's password and click "Enter."
2) Administrator Login: Entrance for operation. The main program is accessed after login, so only the entrance is shown here.
